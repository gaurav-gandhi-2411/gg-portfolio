# Wave 15 content proposals: verification against sources (2026-10-23)

What this is: a verification of the 9 proposals in bot PR #341 ("Wave 15 pipeline
proposals, 2026-10-19"). Those proposals are LLM-consensus output (curator, framer,
verifier models), not human-reviewed claims. This file checks each one against the
source repo README (and the underlying eval artifact where one exists) at the source
repo's default-branch HEAD on 2026-10-23.

This is NOT published copy. None of these sentences is reflected on the site, in a case
study, in `content/provenance.md`, or in the chatbot index. It is a review aid for the
owner. Nothing here has been folded in; that decision is the owner's.

## Method

1. Resolved each source repo's default-branch (`main`) HEAD SHA and read `README.md` at
   that SHA through the GitHub contents API (read-only, no checkout).
2. Found the cited sentence by text (line numbers had drifted for some items) and quoted it.
3. Verdict. VERIFIED: every number and factual claim in the draft appears in the source
   with the same meaning. PARTIAL: some claims match, some do not. UNVERIFIED: the source
   no longer says it. Also checked each source for a nearby historical/superseded/retired label.
4. Followed README links to the underlying artifact (eval JSON, report) at the same SHA
   and confirmed the number where one exists.
5. Date = committer date of the commit that last changed the line (GitHub GraphQL blame on
   `README.md` at the HEAD SHA).

non-breaking hyphens are normalised to ASCII hyphens.
