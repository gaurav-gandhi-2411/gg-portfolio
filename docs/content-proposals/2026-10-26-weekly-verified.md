# Weekly content proposals: verification against sources (2026-10-26)

What this is: a verification of the 11 proposals in bot PR #351 ("chore(content): weekly
curated content proposals", run 2026-10-26). Those proposals are LLM-consensus output
(curator, framer, verifier models), not human-reviewed claims. This file checks each one
against the source repo README (and the underlying eval artifact where one exists) at the
source repo's default-branch HEAD on 2026-10-26.

This is NOT published copy. None of these sentences is reflected on the site, in a case
study, in `content/provenance.md`, or in the chatbot index. It is a review aid for the
owner. Nothing here has been folded in; that decision is the owner's. Same format as
`2026-10-19-wave15-verified.md` (PR #346).

## Method

1. Resolved each source repo's default-branch (`main`) HEAD SHA and read `README.md` (and
   `docs/EVALUATION.md` for triage-iq) at that SHA through the GitHub contents API
   (read-only, no checkout).
2. Found the cited sentence by text and quoted it. Where a proposal is the same claim as a
   #341 proposal checked in #346, the source line was re-read at the current HEAD rather
   than carried over: shelfsense-m5 (`6b423cc`), multimodal-fashion-recommender (`9f4cd7e`)
   and AetherArt (`10eb31c`) HEADs are unchanged since 2026-10-23; triage-iq (`05c333a`,
   was `31cf1b8`) and review-iq (`696031a`, was `b3cabc3`) moved and were re-read.
3. Verdict. VERIFIED: every number and qualifier matches. VERIFIED-ADJUSTED: the facts are
   in the source but the proposal's wording adds, drops or changes a qualifier; a corrected
   sentence is given. HISTORICAL: true but superseded or retired. PARTIAL: part of the
   claim is unsupported. UNSUPPORTED: the source does not say it.
4. Followed README links and the triage-iq number manifest (`docs/numbers/evaluation.json`)
   to the underlying artifact at the same SHA and confirmed the number where one exists.
   An item is flagged README-ONLY when no committed artifact was found behind the number.
5. Date = committer date of the commit that last changed the line (GitHub GraphQL blame on
   the file at the pinned SHA; for artifacts, last commit touching the file).
6. Site conflicts: grepped `content/*.ts`, `content/*.md`, `content/case-studies/*.ts` at
   origin/main `4c8ebff`.

Proposal sentences are verbatim from #351 except that typographic dashes and non-breaking
hyphens are normalised to ASCII hyphens.

Source repo HEADs used: triage-iq `05c333a`, shelfsense-m5 `6b423cc`, review-iq `696031a`,
multimodal-fashion-recommender `9f4cd7e`, AetherArt `10eb31c`.
